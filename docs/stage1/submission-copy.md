# 제출 카피 (OwnDraft — MABC 2026 예선)

## 문제

AI 초안을 받은 뒤 사람들은 상투적인 표현을 지우고, 자신의 실제 경험과 말투를 다시 넣으며,
숫자와 날짜가 바뀌지 않았는지 하나하나 다시 확인하는 반복 작업을 하고 있습니다.

## 해결

OwnDraft는 사실을 먼저 잠그고(Claim Locker), 결과 품질을 높일 정보를 질문하고(Context Interview),
사용자 문체로 편집한 뒤 별도 Critic이 검증합니다(Critic Gate). 잠긴 값은 결정론적 검증으로 확인하며,
실패 시 한 번만 고치고 그래도 실패하면 원문을 유지해 문제 구간을 알려줍니다.

## 차별점

- 한국어 AI 글쓰기 패턴 40종 카탈로그와 결정론적 스캐너
- Claim Locker: 숫자·단위·날짜·이름·기관·제품·URL·직접 인용·부정·조건 보호
- Context Interview: 최대 3개, 한 질문 한 정보, 이미 있는 내용은 재질문하지 않음
- One-Repair Critic Gate: repair 1회 제한, 두 번째 실패 시 원문 유지

## 사회적 가치

AI 사용을 숨기는 대신, 사용자의 실제 기여와 변경 과정을 늘리고 투명하게 보여 줍니다.

## 제외 기능 (안전 경계)

- 워터마크 제거 또는 제거 완료 판정을 하지 않습니다.
- 특정 탐지기(Turnitin, GPTZero 등) 통과를 보장하지 않습니다.
- "AI 탐지 확률 0%" 같은 주장을 하지 않고, 탐지 점수를 목표로 반복 패러프레이징하지 않습니다.
- 사용자에게 알리지 않고 샘플이나 결과를 학습 데이터로 사용하지 않습니다.
